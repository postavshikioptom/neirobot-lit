Задача 052-python-lab-add-class-weights-loss.md
Цель: Сбалансировать обучение модели LiT за счет внедрения Weighted CrossEntropyLoss с использованием сглаженных весов классов, рассчитанных на основе распределения в тренировочном датасете.

Инструкции для Gemini:
1. Изменения в ./python_lab/src/dataset.py
Метод get_class_distribution(self):
Реализовать внутри класса LOBDataset (или аналогичного).
Метод должен возвращать np.ndarray с количеством примеров для каждого класса (Up, Down, Flat).
Важно: Подсчет должен идти по сырым меткам до аугментации (если она есть).
2. Изменения в ./python_lab/scripts/train.py
Расчет сглаженных весов:
Получить counts из датасета.
Реализовать формулу со сглаживанием: weights = total_samples / (n_classes * (counts + smoothing)).
Параметр smoothing (например, 1.0 или 10.0) должен быть доступен через аргументы CLI --class_weight_smooth.
Инициализация Loss:
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
# Перенос весов на устройство
class_weights = torch.tensor(weights, dtype=torch.float32).to(device)
# Инициализация взвешенной кросс-энтропии
criterion = nn.CrossEntropyLoss(weight=class_weights)
Логирование: Вывести итоговые веса в консоль: Effective class weights: [Up: 5.2, Down: 4.8, Flat: 0.4].
3. Изменения в ./python_lab/src/utils.py
Добавить поддержку вывода весов в общий лог-файл эксперимента для последующего воспроизведения.
Аргументация изменений:
Smoothing: Это критическая защита. Если в выборке случайно окажется всего 5 примеров Up, вес без сглаживания будет гигантским. Сглаживание "прижимает" экстремальные значения, сохраняя направление балансировки.
Архитектурная чистота: dataset.py отвечает за знание о данных. train.py отвечает за использование этого знания в оптимизаторе.
Связь с будущим: Мы закладываем фундамент для Task 057 (Focal Loss). Если взвешенная CE не даст нужного MCC, мы легко переключим criterion на Focal Loss, уже имея готовую статистику по классам.
Критическое замечание: Напомните кодеру, что веса классов должны применяться только в функции потерь. Не нужно вручную умножать градиенты или выходы модели. nn.CrossEntropyLoss(weight=...) сделает это эффективно на уровне CUDA-ядра.
