# Задача 317: Улучшение информативности каналов модели LiT

## Диагноз проблемы (на основе output.txt)

### Проблемные метрики:
| Метрика | Текущее значение | Норма |
|---------|-----------------|-------|
| MCC | ~0.00 | > 0.10 |
| Directional Accuracy | ~10% | > 35% |
| Confidence Gap | -0.03 | > 0.05 |
| Hit Rate Up/Down | 8-14% | > 30% |
| Theoretical Edge | отрицательный | > 0 |

### Корневые причины (из кода):

#### 1. Канал Price неинформативен
```
features.py:46-52
price_expr = (price - mid) / mid → mean=0.0017, std=0.0010
```
Значения слишком малы для различения. Канал показывает "где уровень в стакане" (всегда ~0.001 для ask_0), а не предсказывающий сигнал.

#### 2. Канал PastRet вычисляется НЕПРАВИЛЬНО
```
dataset.py (текущий код):
past_ret = log(mid[-1]) - log(mid[0])  # один возврат за 100 тиков
```
**Должно быть три отдельных лог-возврата** для лагов [10, 50, 100]:
- `log(mid[-1]) - log(mid[-10])`  — 10 тиков назад
- `log(mid[-1]) - log(mid[-50])`  — 50 тиков назад
- `log(mid[-1]) - log(mid[-100])` — 100 тиков назад

#### 3. Нет микропрайс-отклонения
Исследования (Cont et al. 2014, DeepLOB 2019) показывают что microprice deviation — второй по силе предсказывающий признак после imbalance.

## План реализации

### Под-задача 1: Добавить канал "Microprice Deviation"
**Файл**: `python_lab/src/dataset.py`, метод `_calculate_6_channels_raw()`

```python
# Microprice — volume-weighted mid price
# Отклоняется от mid в сторону меньшего объема
microprice = (bid_p_0 * ask_v_0 + ask_p_0 * bid_v_0) / (ask_v_0 + bid_v_0 + eps)
microprice_dev = (microprice - mid) / mid  # нормализованное отклонение
```

**Заменить канал Price** (Channel 0) на microprice_dev.
- Price показывает "где уровень" (всегда ~0.001 для ask_0)
- Microprice_dev показывает "куда пойдет цена" (отрицательное = пойдет вниз, положительное = вверх)

### Под-задача 2: Добавить канал "Spread"
**Файл**: `python_lab/src/dataset.py`, метод `_calculate_6_channels_raw()`

```python
# Spread — разница лучший ask и bid, нормализованная к mid
spread = (ask_p_0 - bid_p_0) / mid
```

**Добавить как новый канал (Channel 6)**.
- Spread высокий = высокая волатильность/неопределенность
- Spread низкий = стабильный рынок
- Нормализуется аналогично другим каналам

### Под-задача 3: Исправить вычисление PastRet
**Файл**: `python_lab/src/dataset.py`, метод `_calculate_6_channels_raw()`

```python
# Три отдельных лог-возврата вместо одного
past_ret_10 = log(mid[-1]) - log(mid[-10]) if seq_len >= 10 else 0
past_ret_50 = log(mid[-1]) - log(mid[-50]) if seq_len >= 50 else 0
past_ret_100 = log(mid[-1]) - log(mid[-100]) if seq_len >= 100 else 0

# Агрегируем: среднее (или оставляем как 3 отдельных канала)
# Вариант А: Один канал = среднее из 3 лагов
past_ret = (past_ret_10 + past_ret_50 + past_ret_100) / 3.0
# Вариант Б: Три канала (увеличивает in_channels до 9)
```

**Рекомендация**: Вариант А (один канал = среднее) для минимизации изменений.

### Под-задача 4: Обновить конфигурацию модели
**Файлы**: `python_lab/src/lit_model.py`, `python_lab/src/train.py`

- **in_channels** = 7 (Price→Microprice, +Spread, Vol, Imb, OFI, VIB, PastRet)
