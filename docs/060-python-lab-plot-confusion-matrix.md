Задача 060-python-lab-plot-confusion-matrix.md
Цель: Реализовать генерацию двух типов матриц ошибок (абсолютной и нормализованной) для финальной оценки качества модели на отложенной (holdout) выборке.

Инструкции для реализации:
1. Изменения в ./python_lab/src/utils.py
Функция save_confusion_matrices(y_true, y_pred, class_names, output_dir):
Использовать sklearn.metrics.ConfusionMatrixDisplay.
Генерация двух файлов:
confusion_matrix_raw.png: Матрица с абсолютными значениями (параметр normalize=None). Позволяет видеть реальное количество примеров в каждом классе.
confusion_matrix_normalized.png: Матрица с процентами по строкам (normalize='true'). Критически важна для оценки Recall миноритарных классов Up/Down.
Оформление: Использовать cmap='Blues', добавить сетку и четкие подписи классов (Up, Down, Flat). Увеличить шрифт для читаемости малых процентов.
2. Изменения в ./python_lab/scripts/train.py
Финальный Holdout-тест:
После завершения обучения и выбора лучшего чекпоинта (по MCC), прогнать модель через отложенную тестовую выборку (которая не использовалась ни в обучении, ни в EarlyStopping).
Вызвать save_confusion_matrices для сохранения графиков в bots/SYMBOL/model/.
Логирование: Вывести путь к сохраненным графическим файлам в консоль.
3. Изменения в ./python_lab/requirements.txt
Добавить matplotlib. Seaborn использовать только в случае необходимости специфической кастомизации (предпочтительно обойтись sklearn + matplotlib).
Аргументация изменений:
Две матрицы: Это стандарт для несбалансированных данных. Сырая матрица показывает, что у нас достаточно данных для выводов, а нормализованная — что модель не игнорирует Up/Down в угоду Flat.
Holdout-тест: Матрица ошибок, построенная на тренировочных данных, бесполезна. Только Holdout дает честный ответ на вопрос: "Будет ли бот сливать на реальных данных?".
Минимизация зависимостей: ConfusionMatrixDisplay — мощный инструмент, который работает поверх matplotlib. Отказ от seaborn облегчает поддержку окружения (меньше конфликтов версий).
Критическое требование: Убедиться, что порядок классов в матрице (индексы 0, 1, 2) строго соответствует label_map из metadata.json, чтобы не перепутать сигналы Up и Down при визуальном анализе.
