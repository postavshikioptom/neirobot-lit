# 📋 ИТОГОВЫЙ ПЛАН: Задача 315-2 - Переобучение Normalizer

## 🎯 Цель
Исправить проблему Channel 1 (Volume) = 5.0 везде путем переобучения Normalizer на исправленных данных.

## 🔴 Проблема
После реализации Задачи 315 (исправление двойной нормализации):
- ✅ Channel 2 (Imbalance): диапазон [-0.99, 0.99] - РАБОТАЕТ
- ✅ Channel 3 (OFI): диапазон [-1.5, 1.7] - РАБОТАЕТ
- ❌ Channel 1 (Volume): все еще 5.0 везде - НЕ РАБОТАЕТ

## 🔍 Корневая причина
**Normalizer был обучен на НЕПРАВИЛЬНЫХ данных (до исправления Задачи 315)**

Последовательность:
1. Normalizer обучился на данных с неправильным расчетом Volume (сложение логарифмов)
2. Запомнил статистики: mean ≈ 9.9, std ≈ 2.0
3. Задача 315 исправила расчет (восстановление сырых объемов → сумма → логарифм)
4. Новые данные: mean ≈ 5.7, std ≈ 1.5
5. Normalizer применяет СТАРЫЕ статистики к НОВЫМ данным
6. Результат: Z-score > 5.0 → клиппинг обрезает до 5.0

## ✅ Решение
**Переобучить Normalizer на исправленных данных**

### Подзадача 1: Удалить старый Normalizer
- **Файл:** `bots/FARTCOINUSDT/models/norm_params.json`
- **Действие:** Удалить
- **Команда:** `rm bots/FARTCOINUSDT/models/norm_params.json`
- **Критерий успеха:** Файл удален

### Подзадача 2: Запустить обучение
- **Скрипт:** `python_lab/src/train.py`
- **Действие:** Запустить обучение с параметрами для FARTCOINUSDT
- **Что произойдет:** Normalizer переобучится на исправленных данных
- **Критерий успеха:** Лог "Normalizer fitted on ... samples"

### Подзадача 3: Проверить результаты
- **Проверка 1:** Channel 1 (Vol) имеет РАЗНЫЕ значения (не все 5.0)
- **Проверка 2:** Channel 1 (Vol) имеет нормальное распределение (mean ≈ 0, std ≈ 1)
- **Критерий успеха:** Обе проверки пройдены
