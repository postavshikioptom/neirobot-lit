# Задача №193: Оптимизация производительности: SIMD-ускоренная нормализация данных

[./docs/193-performance-simd-accelerated-normalization.md](./docs/193-performance-simd-accelerated-normalization.md)

## План реализации

1.  **Изменения в зависимостях**:
    - Добавить в `Cargo.toml` крейты `wide = "1"` (для переносимых SIMD-операций) и `aligned-vec = "0.6"` (для выравнивания памяти).

2.  **Изменения в [./src/ml/tensor_builder.rs](./src/ml/tensor_builder.rs)**:
    - Реализовать функцию `normalize_features_simd(features: &mut [f32], means: &[f32], inv_stds: &[f32])`.
    - Использовать `f32x8` или `f32x4` из крейта `wide` для одновременной обработки нескольких элементов вектора.
    - **Оптимизация**: Использовать предварительно вычисленные обратные значения стандартного отклонения (`inv_stds = 1.0 / stds`), чтобы заменить деление на умножение в SIMD-цикле.
    - Добавить скалярную (scalar) реализацию-заглушку для архитектур, не поддерживающих расширенные наборы инструкций, через `#[cfg]` или встроенный механизм автоматического отката (auto-fallback) крейта `wide`.

3.  **Выравнивание памяти (Alignment)**:
    - Обновить структуру тензора, чтобы использовать `AlignedVec` вместо стандартного `Vec<f32>`, обеспечив выравнивание по границе 32 байт (требование для эффективного AVX/AVX2).

4.  **Интеграция в процесс подготовки данных**:
    - Вызывать функцию `normalize_features_simd` непосредственно перед отправкой тензора в ONNX Runtime в [./src/ml/onnx.rs](./src/ml/onnx.rs).
    - Убедиться, что метаданные модели (средние значения и отклонения) загружаются и хранятся в выровненном виде для быстрого доступа.

## Ожидаемый результат
- Существенное ускорение этапа нормализации признаков (до 4-8 раз в зависимости от ширины регистров процессора).
- Снижение задержки подготовки входных данных для модели (Pre-processing latency).
- Код остается переносимым благодаря использованию высокоуровневых абстракций `wide`.
