Задача 002: Создание шаблона global.toml
Цель: Создать файл global.toml в корне проекта, который будет служить базовым набором настроек (fallback) для всех ботов. Эти параметры будут наследоваться каждым процессом, если они не переопределены в индивидуальном bot.toml.

Файл: global.toml (в корне проекта neirobot-lit/)

Инструкции для Gemini:
Создать файл global.toml со следующей структурой:
```
# Глобальные настройки Neirobot LiT (Defaults)

[general]
# Окружение: dev или prod
env = "dev"
# Таймзона для логирования и вывода (ISO формат)
timezone = "UTC"

[logging]
# Уровень логирования: trace, debug, info, warn, error
level = "info"
# Формат вывода: full (подробный), json, compact
format = "full"
# Имя файла лога. 
# ВНИМАНИЕ: Полный путь ВСЕГДА формируется в коде динамически: 
# "bots/{SYMBOL}/logs/{file_name}" для обеспечения изоляции.
file_name = "bot.log"
# Ротация логов по достижению размера
rotate = true
# Максимальный размер лога перед ротацией (в МБ)
max_size_mb = 100

[trading_defaults]
# Максимально допустимая задержка от биржи (ms)
# Если t_now - t_exchange > max_latency_ms, сигнал отбрасывается
max_latency_ms = 500
# Интервал между попытками переподключения (ms)
retry_interval_ms = 1000
# Максимальное количество попыток реконнекта
max_retries = 5

[risk_defaults]
# Глобальный лимит просадки для остановки (в процентах)
drawdown_stop_pct = 5.0
# Rate-limit для REST API (макс. ордеров в минуту на один аккаунт/токен)
max_orders_per_minute = 30
```
Технические требования:
Типизация:
Числовые параметры (ms, retries, orders) — u32.
drawdown_stop_pct — f64.
rotate — bool.
Комментарии: Все комментарии в блоке выше должны быть перенесены в файл. Это поможет при ручной правке конфигов.
Изоляция: Убедиться, что в файле нет параметров, специфичных для конкретной монеты (таких как symbol или model_path).
Почему это важно:
Это "фундамент" конфигурации. В будущем loader.rs будет загружать этот файл первым, а затем "накладывать" на него специфичные настройки биржи и бота. Четкое описание динамического пути в file_name предотвратит создание логов в корневой папке проекта.
