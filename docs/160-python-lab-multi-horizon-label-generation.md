
# Задача №160: Multi-Horizon Labeling & Multi-Task Learning

Согласно [./docs/000-tasks_list.md](./docs/000-tasks_list.md), мы обучаем модель предсказывать будущее на нескольких временных масштабах одновременно (например, 10, 50, 100 событий). Это заставляет Transformer выделять более устойчивые признаки.

## План реализации для Gemini AI Coder:

### 1. Обработка данных в [./python_lab/src/dataset.py](./python_lab/src/dataset.py)
*   **Генерация меток**: Создать функцию, возвращающую тензор меток для списка горизонтов.
*   **Маскирование (Edge Handling)**: Если для сэмпла `i` значение `i + max(horizons) >= total_samples`, помечать отсутствующие горизонты специальным значением (например, `-100` для `IgnoreIndex` в PyTorch).
*   **Консистентность**: Убедиться, что `timestamp` и индексы событий строго упорядочены (задача 012).

### 2. Архитектура модели в [./python_lab/src/lit_model.py](./python_lab/src/lit_model.py)
*   **Multi-Head Output**: Вместо одной головы классификации реализовать набор линейных слоев.
*   **Тензорный формат**: Весь вывод должен собираться в единый тензор формы `(batch, num_horizons, 3)`. Это критично для производительности инференса.
*   **Conditioning (Опционально)**: Добавить возможность использования `Horizon Embedding` как альтернативу разделенным головам для проверки через Optuna.

### 3. Функция потерь и обучение в [./python_lab/scripts/train.py](./python_lab/scripts/train.py)
*   **Masked Loss**: Использовать `CrossEntropyLoss(ignore_index=-100)`, чтобы игнорировать "несуществующее будущее" в конце датасета.
*   **Dynamic Weighting**: Итоговый лосс — взвешенная сумма по горизонтам. Интегрировать веса $w_i$ в пространство поиска **Optuna** (задача 030).
*   **Метрики**: Рассчитывать **MCC** (задача 051) отдельно для каждого горизонта.

### 4. Экспорт и Rust-интеграция ([./src/ml/onnx.rs](./src/ml/onnx.rs))
*   **ONNX Export**: Экспортировать модель с именованным выходом, содержащим все логиты.
*   **Rust Signal Fusion**: В модуле инференса реализовать логику объединения сигналов:
    *   **Weighted Average**: Среднее взвешенное предсказание.
    *   **Confirmation**: Вход в сделку только если все (или большинство) горизонты показывают одно направление.

### 5. Визуализация в TensorBoard (задача 158)
*   Добавить графики `MCC_h10`, `MCC_h50`, `MCC_h100` на один дашборд для визуального сравнения "уверенности" модели на разных дистанциях.

## Аргументация (Спор с Grok):
*   **Согласен**: Использование `ignore_index=-100` — стандартный и эффективный способ обработки неполных данных в конце датасета без обрезки всей выборки.
*   **Согласен**: В Rust (`ort`) работа с одним тензором `(batch, num_horizons, 3)` намного быстрее, чем извлечение нескольких именованных тензоров из сессии.
*   **Согласен**: Веса лоссов должны быть в Optuna. На некоторых монетах горизонт 100 может быть абсолютно непредсказуемым шумом, и его вес должен быть сведен к минимуму автоматически.
