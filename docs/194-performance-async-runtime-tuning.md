# Задача №194: Оптимизация производительности: Тюнинг асинхронного Runtime (Tokio)

[./docs/194-performance-async-runtime-tuning.md](./docs/194-performance-async-runtime-tuning.md)

## План реализации для Gemini

1.  **Изменения в зависимостях**:
    - Добавить в `Cargo.toml` крейт `core_affinity = "0.8"`.
    - Убедиться, что для `tokio` в секции `features` включены `rt-multi-thread` и `parking_lot`.

2.  **Рефакторинг [./src/bin/run-bot.rs](./src/bin/run-bot.rs)**:
    - Удалить макрос `#[tokio::main]` и реализовать ручную инициализацию рантайма через `tokio::runtime::Builder::new_multi_thread()`.
    - Настроить количество рабочих потоков (`worker_threads`) в соответствии с физическими ядрами системы (например, `num_cpus::get()`).

3.  **Привязка потоков к ядрам (CPU Affinity)**:
    - Использовать метод `.on_thread_start()` у билдера рантайма.
    - Внутри замыкания реализовать логику привязки текущего потока к конкретному ядру:
        - Получить список доступных ядер через `core_affinity::get_core_ids()`.
        - Использовать атомарный счетчик для распределения потоков по ядрам (Round Robin).
        - Вызывать `core_affinity::set_for_current()` для фиксации потока.

4.  **Тюнинг планировщика**:
    - Установить `thread_keep_alive` (например, `Duration::from_secs(60)`), чтобы избежать частого пересоздания потоков.
    - Настроить `max_blocking_threads`, чтобы ограничить количество потоков для блокирующих операций (запись в файлы, логирование), предотвращая перегрузку планировщика.
    - Использовать `global_queue_interval`, чтобы сбалансировать частоту проверки глобальной очереди задач и локальных очередей воркеров.

5.  **Валидация**:
    - Добавить логирование при старте бота, подтверждающее успешную привязку потоков: `[Runtime] Worker thread X pinned to core Y`.

## Ожидаемый результат
- Снижение количества переключений контекста (Context Switches) между ядрами процессора.
- Уменьшение "хвоста" задержки (P99 latency) благодаря стабильному кэшу (L1/L2) для каждого потока.
- Более предсказуемая производительность торгового цикла под высокой нагрузкой.
