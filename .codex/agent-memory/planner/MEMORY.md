# Planner Memory

- Пользовательское правило: отвечать всегда на русском языке.
- Для запросов типа "составь план" делать план только для одной главной задачи с подзадачами, без объединения нескольких задач.
- Перед формированием нового плана обязательно читать docs/000-tasks_list.md, чтобы не дублировать выполненные задачи.
- План должен быть максимально конкретным: какие файлы и какие участки кода менять, без общих формулировок.
